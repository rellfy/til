# til front-end

React + Vite SPA. Parses `.til` files in the browser via a WASM build of the
core Rust crate.

## First-time setup

```sh
pnpm install
pnpm build:wasm   # compiles crates/til-wasm into src/wasm
```

`pnpm build:wasm` requires `wasm-pack` and a `wasm32-unknown-unknown` Rust
target.

## Scripts

- `pnpm dev`: start the Vite dev server.
- `pnpm build`: typecheck and produce a production build.
- `pnpm build:wasm`: rebuild the `til-wasm` package into `src/wasm/`.
- `pnpm typecheck`: run `tsc -b` only.
- `pnpm format` / `pnpm format:check`: prettier.
- `pnpm lint`: eslint.

## Layout

- `src/lib/timeline.ts`: thin wrapper around the WASM parser.
- `src/wasm/`: generated by `pnpm build:wasm` (gitignored).
- `src/assets/world-music.til`: bundled sample timeline shown on first load.
